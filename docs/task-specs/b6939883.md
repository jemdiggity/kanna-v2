# Agent-discoverable Kanna guides

## Goal

Make Kanna configuration self-teachable to users' agents from the running version: add catalog-backed topic guides for config, workflows, agents, and tasks; expose them through `kanna-cli guide [topic]` and `kanna_guide {topic}`; and make scaffolded `.kanna/config.json` files and the published schema explain the same semantics.

## Scope and constraints

- Keep the existing task-execution guide as the default and add a discoverable further-topics section.
- Keep guide prose single-sourced in `kanna-tool-catalog`; CLI and MCP render the same catalog content, including hot-reloaded MCP overrides.
- Add `$schema: https://schemas.kanna.build/config.schema.json` wherever Kanna first creates/scaffolds repo config.
- Enrich schema descriptions for config keys, merge behavior, provider/model precedence and coherence, workflow authoring, agent layering, and visibility, reusing catalog guide content where practical in the schema build path.
- Add proportionate catalog, CLI, MCP, scaffold, and schema-build tests. Do not change unrelated behavior or move task-execution content off the default guide.

## Done when

All guide topics are usable and tested through CLI and MCP, default output advertises them, generated config carries `$schema`, schema descriptions carry the required semantics, relevant checks pass, and no background processes remain.

## Optional follow-up (not in scope)

Once agent documentation is public, list Kanna on Context7 (`mcp.context7.com`) so external agents can retrieve versioned Kanna docs.

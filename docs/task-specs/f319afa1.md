# Stage-entry provenance

## Goal

Record and surface how each workflow stage was entered: `auto`, `operator`, `manager`, or `unspecified`.

## Scope

- Accept an optional declared advance source from desktop, mobile, CLI, and MCP callers; preserve older-client compatibility as `unspecified`.
- Store the trigger on the spawned main `stage_run`, including across post-driven advances; engine policy transitions use `auto`.
- Expose the trigger in `stage.changed`, task run detail/history, `$STAGE_TRIGGER`, and the shared task-environment preamble.
- Teach the built-in task manager to declare `manager`, update server/tool documentation, and cover server, prompt, desktop, mobile, catalog, and real advance wiring.

No caller authentication or changes to revision-origin semantics are included. The only schema change is one nullable `stage_run.trigger` column; existing rows surface as `unspecified`.

## Done

All entry paths produce the correct trigger, every agent can read it through its prompt and task detail, compatibility behavior and docs are covered, formatting and type checks pass, targeted Clippy introduces no new warnings, and `./kd test all` passes.

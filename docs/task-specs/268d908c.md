# Review verdict completion on re-review

## Goal

Prevent Codex review agents from parking after a re-review summary without recording a verdict, as observed on 2026-08-23 in tasks `da8391f0`, `c21c9405`, and `3d928a67`.

## Scope and constraints

Trace the built-in single-reviewer agent definition and the engine prompt composed after a revision, then make the verdict-completion contract explicit in the review agent documentation and re-review prompt. Keep the change to prompt/documentation surgery plus a focused engine test; do not add polling. Add an engine-side parked-state backstop only if it fits the existing architecture cheaply.

## Done when

Re-review prompts end with an unmissable requirement to call `kanna_complete_stage` or `kanna_request_revision`, the agent definition states that a summary alone is unfinished, and focused tests prove the prompt composition preserves that final instruction.

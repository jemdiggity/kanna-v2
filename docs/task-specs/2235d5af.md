# Mobile repo explorer swipe navigation

Owner request (2026-08-23): add browser-style swipe back and forward navigation to the mobile repository explorer.

## Scope

- A left-edge rightward swipe goes back: file to its directory, or directory to its parent.
- A right-edge leftward swipe goes forward to the directory or file most recently left by back navigation.
- Header Back uses the same history behavior, and tapping a directory or file clears forward history.
- Edge-only gestures track the finger and do not capture mid-screen WebView horizontal scrolling or FlatList scrolling/pull-to-refresh.
- Unit/component tests cover back, forward, and forward-history truncation; gesture feel is manually verified.

## Constraints and completion

- Keep this JS-only and OTA-deliverable; do not change mobile `runtimeVersion` or native configuration.
- The task named gesture-handler/Reanimated as already available, but this checkout declares neither dependency and its existing swipe-to-pin uses React Native `PanResponder`/`Animated`. Use that existing JS-only pattern rather than adding native dependencies that would contradict the OTA constraint.
- Work is done when navigation behavior and tests are implemented and the mobile TypeScript check and focused tests pass.

# Task 32e63197: polished mobile task-card swipes

## Goal

Make the mobile task list's swipe-to-pin/unpin and swipe-to-dismiss gestures feel physical and polished while remaining responsive on an iPhone.

## Scope and constraints

- Animate the revealed action with drag progress and threshold emphasis, spring cancelled swipes back, spring committed pin swipes into a reordered settle, and slide committed dismissals out while collapsing their list gap.
- Respect reduced motion by replacing physical movement with simple fades.
- Stay in the app's existing React Native `Animated` family and keep the change JS-only. Do not add native dependencies or bump `runtimeVersion`; because `expo-haptics` is not installed, omit the threshold haptic and document that limitation.
- Preserve the existing swipe grammar, accessibility actions, local pin/dismiss persistence, and error reporting. Do not change desktop/server behavior.

## Done when

Threshold logic, reduced-motion behavior, and delayed completion callbacks have component/unit coverage; a dated E2E gap note records why animation visuals remain manual and gives an iPhone checklist; `pnpm --filter @kanna/mobile test` and `pnpm --filter @kanna/mobile typecheck` pass.

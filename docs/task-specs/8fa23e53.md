# Desktop release-train promotion model

## Goal

Make `tools/kd` support the branch-based release train: cut `release/X.Y` from advancing `origin/main`, ship and soak branch RCs, and promote the verified branch RC even while main continues moving.

## Scope and constraints

- Reword guard 4 and the release-candidate spec so the in-`kd` remedy (`kd release cut --minor`, then ship a branch RC) comes first, the raw-git cut-at-RC escape is last-resort, and guard 4's main arm is explicitly mechanical while guards 1 and 3 own soak safety.
- After promotion, make a bare main staging ship default to the next minor series from the production floor; reserve patch releases in the production series for branch-shipped backports.
- Make dormant-series-branch failures state-aware and never recommend a non-fast-forward push.
- Preserve every release invariant named in the task, especially immutable RC identity, exact-tip branch provenance, lineage validity, staging freeze, fail-closed reads, and the single gate path shared by status, dry-run, and promotion.
- Extend runner-mocked coverage for the full moving-main branch lifecycle, post-promotion default derivation, and dormant-branch messaging. Do not perform live release operations or touch mobile OTA, signing, retention, or staging-lineage semantics.
- Optional `--at-rc`/auto-cut ergonomics land only if they are necessary and justify their extra surface. They are deliberately omitted: the branch-RC train is complete without another branch-mutating surface, while immutable-identity handling for an old-RC cut would add substantial safety-sensitive code and tests for a last-resort path.

## Version-default consequence

An operator who intentionally wants a main-sourced patch derivation must now pass `--patch`; a bare main ship after promotion starts the next minor series. This is intentional and does not weaken the explicit override.

## Done when

The implementation, executable tests, CLI help, and release-candidate documentation agree; `tools/kd` tests and `pnpm exec tsc --noEmit` pass; and the spec accurately records any deliberate omissions or consequences.

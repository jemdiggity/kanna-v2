# Mobile repo explorer line references

Fix the mobile repository file viewer so its no-selection reference uses the native WebView's actual visible scroll position, and add explicit line-number selection with single-line, range, and clear interactions plus a button label that previews the referenced lines.

Live DOM text selection takes precedence so optional quoted text continues to work; explicit line-number selection is next, and the actual native viewport line is the fallback. Cover these behaviors in the generated viewer-document tests. This is a JS-only, OTA-deliverable change: do not change mobile `runtimeVersion`.

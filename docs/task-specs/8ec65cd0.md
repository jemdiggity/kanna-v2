# Localized portal subscription price

## Terms

- Replace the subscribe page's all-currency list with one best-effort price selected from the visitor's browser locale region: JPY 500 for Japan; USD 5 for the US and unknown regions; CAD 5 for Canada; AUD 5 for Australia; GBP 5 for the UK; and EUR 5 for euro-area regions.
- Format the selected static amount with `Intl.NumberFormat`, show that it is monthly, and quietly explain that the actual local currency is chosen at Checkout. Keep a non-default `VITE_KANNA_CLOUD_PRICE` as an explicit display override.
- Preserve the Stripe-native checkout request as exactly `{ plan: "monthly" }`; do not fetch prices from Stripe or send a currency.
- Cover JP, US, GB, a euro-area locale, unknown fallback, and formatted rendering with portal component tests. The work is done when the portal tests and build pass.

Owner directive: Jeremy Hale, 2026-08-22, requested that the portal show only the visitor's inferred local currency rather than all sale currencies, with the constraints above.

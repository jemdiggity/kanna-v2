# Repo default-branch metadata

## Goal

Persist the authoritative remote default branch when registering a repository, with provenance, and provide a supported way to reconcile stale metadata.

## Scope

- Make both server and desktop registration prefer the remote `origin` HEAD symref, using local heuristics only when no remote exists.
- Expose repo metadata reconciliation (at minimum `defaultBranch`) through the server and agent tool catalog, including drift/result provenance.
- Make a missing recorded remote-default-branch snapshot a visible definition-resolution error rather than a built-in fallback.
- Cover authoritative registration, reconciliation, and definition-resolution failure across real Git/server boundaries.

Ahead/behind robustness and desktop remote-task file views are out of scope. Task creation cutting a worktree from the stale recorded branch is tracked separately as task `47b7cb85`; this task fixes the metadata and definition-resolution causes but does not take over that task's start-point work.

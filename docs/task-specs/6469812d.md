# Task 6469812d: reuse the mobile relay control connection

## Goal

Keep one authenticated relay control WebSocket alive while the mobile app is foregrounded, and reuse it for sequential `list_active_desktops` refreshes and other control invokes instead of opening a connection per refresh.

## Scope and constraints

- Reconnect a dropped control socket with the existing stream-style bounded backoff, and close/cancel it when the app backgrounds or the client is disposed.
- Preserve refresh cadence and data semantics; this is transport lifecycle work only.
- Reuse the existing per-desktop KSP stream connections where their protocol permits, but do not merge the relay-level `list_active_desktops` command into a desktop tunnel. Task e4176cb8 is not present in this branch, so there is no landed home-screen persistent connection to adopt here.
- Do not change native mobile code/config or `runtimeVersion`.

## Done when

Transport/controller tests prove sequential refreshes open one control socket, drops reconnect after backoff, and backgrounding closes the socket until foregrounded; mobile tests and TypeScript checks pass, plus relay tests if relay code changes.

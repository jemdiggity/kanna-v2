# Push-only mobile notifications

## Goal

Route every `kanna_notify_mobile` request through the relay push path, regardless of active LAN/KSP streams, so foregrounded and backgrounded mobile apps receive visible system notifications without LAN suppression.

## Scope

- Remove server LAN mobile-notification delivery and its KSP capability, response accounting, catalog language, and tests; retain signed-in relay push as the current transport.
- Remove the mobile LAN notification listener and in-app banner, configure Expo foreground presentation, and preserve push task-opening in every app state.
- Import `docs/specs/anonymous-push-notifications.md` from `task-38025180` and amend its delivery design to push-only.
- Add integration coverage for relay queuing with an active mobile LAN stream and mobile coverage for foreground presentation and deep-link handling.
- Do not implement anonymous push credentials and do not bump the mobile runtime version for these JS-only changes.

# Retry-safe context-less completion

Prevent a retry of a context-less post completion from completing the next stage's main run. MCP and both CLI completion paths must always send the deterministic completionAttemptKey. Preserve explicit run binding and the resolution tests from task 756c4972; render ambiguity ids plainly.

Persist context-less attempts in a new SQLite table keyed by (task_id, attempt_key), holding the original run id and immutable verdict JSON. This schema change is needed because existing dedupe lives in optional, prunable run-context files. Record the binding atomically with the run verdict; look it up before resolving any running run. An identical retry returns the existing successful acknowledgement without transition; key reuse with a different verdict conflicts. Explicit run-bound calls retain their existing lineage handling, so independent runs may use identical prose. Context-less identical prose is deliberately the same attempt for the task's lifetime; a new identical verdict requires explicit run context.

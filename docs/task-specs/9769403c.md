# Mobile task identity visibility

## Goal

Keep a durable task ID visible with several-hundred-character prompts in mobile list rows and collapsed or expanded task-detail headers.

## Scope and constraints

- Change only `apps/mobile` and documentation. Keep the expanded detail identity outside the prompt scroller; show the collapsed ID whenever a durable/displayable ID exists; place list IDs beside titles while middle-ellipsizing long IDs so titles remain legible.
- Cover these layouts with unit and LAN/Appium smoke E2E tests, and visually verify them in a separate iOS 26.5 simulator. This is JS-only: runtimeVersion remains `2.2.3`.

## Done when

Long prompts leave the ID visible in both detail-header states, 64-hex IDs and long titles are both legible in rows, product behavior matches, checks pass, and simulator screenshots plus build/runtime details are recorded here.
